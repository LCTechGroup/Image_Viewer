使用说明

本软件完全离线运行，不联网、不上传文件，支持图片、视频、离线网页、PDF 和文本文档的本地阅览。

1主页与文件夹

  • 点击 选择文件夹，授权一个手机上的文件夹后即可浏览其完整目录结构
  • 授权过的文件夹会出现在「历史文件夹」列表，点右侧「×」可删除记录（不会删除原文件）
  • 授权丢失的历史文件夹、已被移动或删除的收藏会变成红底白字的「已失效」项，点击确认后即可删除；文件重新出现时会自动恢复正常
  • 网页版「收藏」页可导出收藏为 JSON 文件备份，也可从 JSON 导入，导入默认与现有收藏合并去重；跨文件夹的收藏打开时仍需重新授权一次仅网页
  • 清理缓存 可分类清理：阅读器内容缓存（图片缩略图、视频封面及离线网页临时文件）、文件夹路径缓存、阅读位置等浏览历史、个性设置、自定义标签（App），也可一键清理全部；历史文件夹、授权与收藏始终保留
  • 上次浏览 可直接回到最近一次访问的文件夹，并精确恢复到上次浏览的子目录；应用重启后停在主页，点「继续浏览」或「上次浏览」即可进入，网页版会先重新请求一次文件夹授权
  • 再次打开授权过的文件夹时先用本机索引秒进，随后在后台自动检查文件增删，有变化会提示「目录已更新」并保留当前位置；顶栏刷新键可立即手动更新

2文件浏览页面

  • ‹ 返回上一层，在根目录时返回主页
  • ↻ 重新读取当前目录，文件有增删时用来刷新
  • ⤨ 右下角随机键（主页键上方）打乱当前目录内容，再按一次恢复名称排序；进入子文件夹或切换目录会自动恢复
  • ⌕ 按名称搜索文件和文件夹，空格分隔的多个关键字需全部命中；App 端同时搜索自定义标签：文件名按子串匹配，标签需完整一致才命中；树状 / 单层图标键切换「含子目录 / 仅当前层」，旁边漏斗键可按文件夹、图片、视频、离线网页、文本文档、PDF 过滤；再次打开搜索会直接列出上一次的结果列表（本次使用期间，连同所在根文件夹一起记住，可跨文件夹/根目录直接跳转），输入新词才重新搜索；点文件夹直接进入，点文件跳到其所在目录并高亮该卡片，不自动打开标签匹配仅 App
  • 过滤 键在搜索与重新读取之间，点开后勾选要显示的类别（文件夹 / 图片 / 视频 / 离线网页 / 文本文档 / PDF），可多选；全部不选即显示全部内容，启用时过滤键变白；只对当前目录生效，进入其他目录自动恢复。App 端过滤弹窗内还可按标签过滤：搜索并点选已有标签，选多个标签时按同时满足（AND）处理，不选标签即无标签限制，标签与类别条件叠加生效标签过滤仅 App
  • 仅网页长按文件夹或支持浏览的文件会自动收藏 / 取消收藏，收藏的文件可以在主页的「收藏」列表内查看 / 跳转，跨授权树的跳转会自动重新申请授权
  • 仅 App长按文件夹或支持浏览的文件则会唤起自定义标签编辑页面，在此页可以点击收藏键收藏 / 取消收藏，也可为当前卡片创建或选择已有标签添加，每个标签最多32字，最多添加40个标签；添加的前几个标签会显示到卡片下方，在编辑页长按已添加的标签可以设置优先显示，最多设置三个
  • 标签仅缓存在本机，不会修改文件或生成旁置文件；完整刷新目录时文档 ID 不变的改名 / 移动会自动跟随，删除或 ID 改变时保留为失效标签，编辑目标项时可手动重新关联；主页「清理缓存」中的「管理本地标签」可逐条查看和删除，普通缓存清理不会移除标签
  • ⌂ 右下角主页键返回主页，当前阅读位置会被记住；随机键正上方是回到顶部键，向下滚动后才出现
  • 图片和视频封面优先加载可见区域，远处缩略图按需释放；网页版使用较小缩略图并缓存在本机，图片阅读时仍加载原图。无法提取视频帧时保留播放图标

3图片查看界面

  • 点击图片进入，轻点屏幕中央显示 / 隐藏菜单，滑动翻页
  • 模式键循环切换：↓ 上下（默认连续条漫）、» 左右翻页、« 右左翻页；上下模式可再按条漫键切换连续滚动与整页吸附
  • 双指捏合可放大至 5 倍，放大后单指拖动，翻页时自动恢复初始大小和位置
  • 菜单打开时底部进度条默认显示，拖动跳转，拖动时上方显示目标页缩略图，松手后才翻页；一次手势最多翻一页
  • 顶部太阳键切换屏幕常亮，开启后阅读时屏幕不会自动息屏，退出阅览自动恢复，设置自动记忆
  • 右上角模式键正下方有横屏键，可锁定横屏观看，再按恢复竖屏；退出阅览自动还原仅 App
  • 音量键翻页：音量减前进、音量加后退仅 App
  • 阅读位置自动记忆，主页出现「从上次位置继续」卡片；随机排序的进度单独记录

4视频播放界面

  • App 使用原生播放器；网页版支持浏览器可解码的 MP4 / WebM，MP4 使用分片缓冲。不支持的容器或编码会提示使用 App，支持程度取决于设备和浏览器
  • 双击切换暂停 / 播放；单击只显隐菜单
  • 长按画面加速播放，松开恢复；画面中部横向拖动可快进 / 快退，中央显示目标时间
  • 右上角倍速面板分别调节播放速度与长按加速（0.25–5.0 倍，每 0.25 一档）；App 每次打开默认 1 倍并记住长按速度，网页版记住两项速度
  • 顶栏标题右侧的模式键切换单次 / 单个循环，两端一致；底栏末尾的播单键仅在文件夹内有多个视频时出现，带首帧缩略图，点击切换，当前视频高亮
  • App 播放时屏幕默认常亮，暂停或播完后恢复自动息屏；网页版切到后台会暂停，回来后手动继续
  • 倍速键正下方的横屏键可进入 / 退出全屏，再次点击或关闭播放器会还原

5离线网页浏览界面仅 App

  • 点击 .mht / .mhtml 文件打开，文字、图片、样式在归档内完整离线还原，无需联网
  • 支持双指缩放；页面内链接不会跳转到外部网站
  • 顶栏显示文件名，‹ 返回文件列表；此类文件同样可以长按收藏

6文本文档阅读界面

  • 点击 .txt 文件进入，自动识别 UTF-8 / UTF-16 / GBK 等编码，不乱码
  • 模式键循环切换：» 左右翻页（默认）、↓ 上下滑动、« 右左翻页；横排滑动停稳自动吸附整页，屏幕左右三分之一点击翻页、中间显隐菜单
  • 进度条上方可调节字号（A）、行距（上下箭头），切换白纸 / 纸黄 / 黑底三种背景，设置自动记忆
  • 顶栏目录键会自动识别「第 X 章 / 回 / 节 / 卷」等标题生成目录，点击直接跳章，当前章高亮；拖动进度条时会浮出当前章节名
  • 进度条可拖动跳转，显示百分比和页码；每个文件的阅读位置分别记忆
  • 长按文档卡片可收藏，在主页「收藏」中快速回来；阅读位置同样按文件分别恢复
  • 音量键翻页、返回键退出与图片查看一致音量键仅 App

7PDF 文档阅读界面仅 App

  • 点击 .pdf 文件进入，内置 pdf.js 离线解析，支持中文与内嵌字体，无需联网
  • 默认 ↓ 纵向条漫连续滚动（顶栏条漫键可切纵向整页翻页），模式键可切 » 左右翻页、« 右左翻页；翻页与图片阅读器同为原生吸附整页，跟手不跳页
  • 双指捏合 1–5 倍缩放，双击在 1 倍 / 2 倍间切换；整页模式放大后可单指拖动，翻页自动复位
  • 进度条拖动按页跳转并浮出页码；支持横屏锁定与屏幕常亮，阅读位置按文件分别记忆，音量键可翻页；PDF 卡片可长按收藏

8多浏览页仅 App

  • 左下角多任务悬浮球显示浏览页数量，拖动可改变位置（网格、阅读器、视频、网页归档内位置通用），点击展开居中级列表；浏览网格时常亮，阅读 / 播放时半透明，拖动 / 展开时变清晰。「＋ 新建」打开独立主页，可选择另一文件夹，最多保留 32 页。每页记住目录、滚动、过滤、随机顺序及搜索；点页名切换，点 × 关闭，至少保留一页
  • 阅读图片 / 文本 / PDF 或播放视频、浏览网页归档时也可直接切浏览页：当前阅读会暂时退出并记住文件与进度，切回该页自动重开并续上（视频重新加载需 1~2 秒）。多页与位置在应用重启后仍会恢复到浮球列表中，但不会自动打开；浮球位置会记住，清理个性设置可重置。目录读取中请稍候再切页
  • 应用冷启动的时候会自动回到主页，此时点击「上次浏览」可恢复上次浏览的子目录

9App 版与网页版的区别

  • 仅 App 支持：多浏览页、本地自定义标签、离线网页（.mht）与 PDF 文档浏览及其收藏、系统方向锁定、音量键翻页。网页版支持图片、文本、视频的浏览与收藏及视频播单，浏览器解不了的格式可改用 App
  • 两版都会记住最近选择的文件夹及上次浏览的子目录，保存在本机：App 在授权仍有效时无需重选，启动后从主页继续；网页版受浏览器安全限制可能需要再次授权。目录索引和缩略图保存在本机，点「上次浏览」可恢复子目录，清缓存后会重新生成
  • 图片阅览、条漫 / 翻页、缩放、文本文档阅读、文件夹与文本文档收藏、主页历史 / 收藏列表、子目录恢复、搜索、随机排序等功能两版一致；网页版打开其他文件夹的收藏或历史记录时会重新请求一次授权
  • 网页版建议用安卓 Chrome 或 Edge 打开本页面，以支持文件夹记忆；其他浏览器仍可手动选择文件夹浏览
