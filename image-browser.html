使用说明

本软件完全离线运行，不联网、不上传文件，支持图片、视频、离线网页和文本文档的本地阅览。

1主页与文件夹

  • 点击 选择文件夹，授权一个手机上的文件夹后即可浏览其完整目录结构
  • 授权过的文件夹会出现在「历史文件夹」列表，点右侧「×」可删除记录（不会删除原文件）
  • 长按任意子文件夹或 .txt 文本文档可收藏，在「收藏」页快速重开，再次长按取消；收藏内容属于其他文件夹时，App 自动切换授权树，网页版会重新请求一次文件夹权限
  • 清理缓存 释放已加载的缩略图缓存和阅读记录；文件夹授权与收藏会保留
  • 上次浏览 可直接回到最近一次访问的文件夹，并精确恢复到上次浏览的子目录；App 打开即自动恢复，网页版会先重新请求一次文件夹授权

2文件浏览页面

  • ‹ 返回上一层，在根目录时返回主页
  • ↻ 重新读取当前目录，文件有增删时用来刷新
  • ⤨ 随机排序：打乱当前目录内容，再按一次恢复名称排序；进入子文件夹或切换目录会自动恢复
  • ⌕ 按名称搜索文件和文件夹，空格分隔的多个关键字需全部命中；可用「含子目录 / 仅当前层」键切换范围
  • ⌂ 右下角主页键返回主页，当前阅读位置会被记住
  • 图片显示缩略图、视频显示首帧封面（多个视频时依次加载，约 6 秒取不到则显示播放三角）

3图片查看界面

  • 点击图片进入，轻点屏幕中央显示 / 隐藏菜单，滑动翻页
  • 模式键循环切换：↓ 上下（默认连续条漫）、» 左右翻页、« 右左翻页；上下模式可再按条漫键切换连续滚动与整页吸附
  • 双指捏合可放大至 5 倍，放大后单指拖动，翻页时自动恢复初始大小和位置
  • 底部进度条拖动跳转，拖动时上方显示目标页缩略图，松手后才翻页；一次手势最多翻一页
  • 右上角模式键正下方有横屏键，可锁定横屏观看，再按恢复竖屏；退出阅览自动还原仅 App
  • 音量键翻页：音量减前进、音量加后退仅 App
  • 阅读位置自动记忆，主页出现「从上次位置继续」卡片；随机排序的进度单独记录

4视频播放界面仅 App

  • 原生硬解播放，支持高码率 / 4K；拖到未缓冲区域显示「缓冲中…」，不会卡死
  • 280 毫秒内双击暂停 / 播放；单击只显隐菜单
  • 长按画面 0.2 秒以上加速播放，松开恢复；画面中部横向拖动可快进 / 快退，中央显示目标时间
  • 右上角面板分别调节播放速度与长按加速（0.25–5.0 倍，每 0.25 一档，自动记忆）
  • 循环键切换「1x 单次播放 / ↻ 单个循环」；同一文件夹有多个视频时可打开播单，带首帧缩略图，点按切换
  • 倍速键正下方有横屏键，可锁定横屏观看，再按恢复竖屏仅 App
  • 返回键优先关闭播放器，回到文件列表

5离线网页浏览界面仅 App

  • 点击 .mht / .mhtml 文件打开，文字、图片、样式在归档内完整离线还原，无需联网
  • 支持双指缩放；页面内链接不会跳转到外部网站
  • 顶栏显示文件名，‹ 返回文件列表；此类文件同样可以长按收藏

6文本文档阅读界面

  • 点击 .txt 文件进入，自动识别 UTF-8 / UTF-16 / GBK 等编码，不乱码
  • 模式键循环切换：» 左右翻页（默认）、↓ 上下滑动、« 右左翻页；横排滑动停稳自动吸附整页，屏幕左右三分之一点击翻页、中间显隐菜单
  • 进度条上方可调节字号（A）、行距（上下箭头），切换白纸 / 纸黄 / 黑底三种背景，设置自动记忆
  • 顶栏目录键会自动识别「第 X 章 / 回 / 节 / 卷」等标题生成目录，点击直接跳章，当前章高亮；拖动进度条时会浮出当前章节名
  • 进度条可拖动跳转，显示百分比和页码；每个文件的阅读位置分别记忆
  • 长按文档卡片可收藏，在主页「收藏」中快速回来；阅读位置同样按文件分别恢复
  • 音量键翻页、返回键退出与图片查看一致音量键仅 App

7App 版与网页版的区别

  • 仅 App 支持：视频播放、离线网页（.mht）浏览及其收藏、横屏锁定、音量键翻页；这些功能在网页版中视频显示为灰色卡片、.mht 无法打开
  • 两版都会记住最近选择的文件夹及上次浏览的子目录，保存在本机：App 授权一次永久免重选、启动即自动恢复；网页版受浏览器安全限制，再次打开时可能需要重新授权一次，且不保留已加载文件的缓存，点「上次浏览」授权后同样能恢复到子目录
  • 图片阅览、条漫 / 翻页、缩放、文本文档阅读、文件夹与文本文档收藏、主页历史 / 收藏列表、子目录恢复、搜索、随机排序等功能两版一致；网页版打开其他文件夹的收藏或历史记录时会重新请求一次授权
  • 网页版建议用安卓 Chrome 或 Edge 打开本页面，以支持文件夹记忆；其他浏览器仍可手动选择文件夹浏览
